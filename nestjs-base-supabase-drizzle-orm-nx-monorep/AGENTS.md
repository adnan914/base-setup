# Repository Agent Guidance

For backend implementation, review, refactoring, API documentation, security,
database schema, migration, and query work, read and follow:

- `skills/nestjs-backend-standards/SKILL.md`

For Nx workspace structure, project boundaries, targets, task caching,
affected execution, generators, and monorepo refactoring work, read and follow:

- `skills/nx-monorepo-standards/SKILL.md`

Keep the backend contract aligned with the local skill when adding or changing
NestJS controllers, resolvers, DTOs, GraphQL types, services, guards, pipes,
Drizzle schema, migrations, database access, configuration, or tests.

Keep Nx project graph ownership, app-to-library boundaries, target inputs, and
verification commands aligned with the local Nx skill when changing workspace
configuration, project configuration, scripts, apps, or shared libraries.
