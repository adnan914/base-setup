# Repository Agent Guidance

For backend implementation, review, refactoring, API documentation, security,
GraphQL, database schema, migration, query, configuration, and test work, read
and follow:

- `skills/nestjs-backend-standards/SKILL.md`

Keep the backend contract aligned with the local skill when adding or changing
NestJS controllers, resolvers, DTOs, services, guards, pipes, Drizzle schema,
migrations, database access, configuration, or tests.

For Nx workspace, monorepo structure, app/library project configuration,
targets, caching, TypeScript workspace aliases, project boundaries, root task
scripts, and affected-task verification work, read and follow:

- `skills/nx-monorepo-standards/SKILL.md`

Use both local skills when a backend change also changes Nx projects, targets,
workspace configuration, or app/library boundaries.
